# Documentation

This directory centralizes all high-level documentation for the ML production stack.

- `architecture/`: diagrams, ADRs, and model cards.
- `api/`: OpenAPI specifications and endpoint references.
- `roadmap.md`: strategic plan and upcoming milestones.
- `templates/`: reusable documentation templates (README, reports, etc.).

Publish these docs via MkDocs (see `mkdocs.yml`) to share with stakeholders.
