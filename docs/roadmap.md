# Roadmap

## Q4 2025
- Productionize MLflow tracking server with S3-backed artifact store.
- Implement Prometheus metrics and Grafana dashboards for model serving.
- Launch MkDocs documentation site with GitHub Pages automation.

## Q1 2026
- Introduce Feast feature store integration for shared features between training and serving.
- Add continuous retraining pipeline orchestrated by Prefect with human-in-the-loop approval.
- Deploy drift detection via Evidently AI with automated alerts.

## Q2 2026
- Implement canary releases with Argo Rollouts.
- Enable shadow deployments for evaluating new models before promotion.
- Harden security posture with automated vulnerability scanning (Trivy, Grype) and secret rotation policies.
