# Notebooks

Curated notebooks demonstrating data exploration, feature engineering, and model documentation.

Suggested conventions:

1. `01_exploration.ipynb` – exploratory data analysis and dataset profiling.
2. `02_feature_store_demo.ipynb` – feature store interaction (Feast/Hopsworks).
3. `03_model_card.ipynb` – generates model card artifacts for deployed models.

Keep notebooks lightweight and strip execution outputs via `nbstripout` (hook configured in pre-commit).
